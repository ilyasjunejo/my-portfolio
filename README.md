# Data Science & AI Portfolio

This repository contains the React/TypeScript UI components for my personal portfolio. The portfolio is intended to present my learning journey, selected projects, skills, and contact links in one place.

## Current focus

I'm learning **Data Science, Machine Learning, and Generative AI** and using practical projects to strengthen my Python and analytical skills.

## Component overview

The repository currently includes UI components for:

- **Hero and About** — introduction and background
- **Projects and ProjectCard** — selected work
- **Skills** — tools and learning areas
- **Experience and Opportunities** — experience and goals
- **Contact** — ways to connect
- **CaseStudyModal and AddProjectModal** — project details and project editing UI
- **DataEditor** — portfolio content editing UI

## Tech

- React
- TypeScript / TSX
- Tailwind-style utility classes
- Lucide icons

## Repository status

This repository currently contains component source files. A package manifest, application entry point, and complete build configuration are not present in the visible root files, so a clean local install or deployment cannot be documented reliably yet. To make the portfolio straightforward for others to run, the next improvement is to add the app scaffold, package scripts, and setup instructions.
